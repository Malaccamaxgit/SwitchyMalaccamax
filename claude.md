# Claude Code Project Guidelines (Windows 11)

## Environment Rules
- **OS:** Windows 11
- **Pathing:** Always use absolute Windows-style paths (e.g., C:\Path\To\File) when reading or writing files.
- **Line Endings:** Use CRLF line endings for all file modifications.

## Build & Test Commands
- Build: npm run build
- Test: npm test

## Coding Style
- Follow the existing formatting in the project.
